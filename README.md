## Troubleshooting

### 401 Unauthorized - неверный ключ

**Что видел:** ошибка 401 Unauthorized. Написано, что ключ не подходит.
**Почему:** в настройках GIGACHAT_CREDENTIALS лежит неправильный ключ:
опечатка, лишние пробелы или кавычки, либо ключ уже старый.
**Что сделал:** проверил ключ, убрал лишнее, вставил правильный. Заодно
убедился, что если ключ снова не сработает, скрипт не упадёт, а ответит
через [HuggingFace].

### 429 Too Many Requests - слишком много запросов

**Что видел:** ошибка 429 Too Many Requests. Сервер пишет, что запросов
слишком много.
**Почему:** я отправлял запросы слишком часто или запускал несколько
скриптов сразу. У сервиса есть лимит.
**Что сделал:** стал делать паузы между запросами и уменьшил их количество.
Если лимит всё равно превышен, запрос уходит через [HuggingFace], и всё
продолжает работать.
